⚠️ ドメイン承認エラー (auth/unauthorized-domain)

現在のドメイン（Webサイトのアドレス）が Firebase Authentication の承認済みドメインに登録されていません。

【追加が必要な現在のドメイン】

【設定手順（約30秒）】

  1. Firebase Console ＞ プロジェクト saino-chokubai-7448c
  2. 左メニュー Authentication ＞ 「設定」 ＞ 「承認済みドメイン」 タブを開く
  3. 「ドメインの追加」 をクリックし、上記でコピーしたドメイン名を貼り付けて保存してください

⚠️ Firestore データベースの権限エラー (Missing or insufficient permissions)

Firebase コンソールで Cloud Firestore のセキュリティルールが設定されていないため、タスクの保存・取得が制限されています。

【解決手順（約1分）】

  1. Firebase Console ＞ プロジェクト saino-chokubai-7448c を開く
  2. 左メニュー Firestore Database ＞ 「ルール」 タブをクリック
  3. 以下のコードを貼り付けて右上 「公開」 ボタンを押してください
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/tasks/{taskId} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}

ステップ1: GitHub Pages への公開手順

  1. GitHub で新しいリポジトリを作成します（例: my-task-app）。
  2. このコードを index.html という名前でリポジトリの直下にコミット・プッシュします。
  3. GitHub の Settings > Pages に移動し、Branch を main / root に設定して Save します。

ステップ2: Firebase 承認済みドメインの登録 (重要!)

Google ログインを機能させるため、以下のドメインを許可設定してください。

  1. Firebase Console にアクセスし、プロジェクトを開きます。
  2. 左メニュー Authentication > 設定 > 承認済みドメイン (Authorized domains) タブを開きます。
  3. 「ドメインの追加」 をクリックし、GitHub Pages のドメイン（例: username.github.io）を入力して保存します。
