⚠️ Firestore データベースの権限エラー (Missing or insufficient permissions)

Firebase コンソールで Cloud Firestore のセキュリティルールが設定されていないため、タスクの保存・取得が制限されています。

【解決手順（約1分）】

  1. Firebase Console ＞ プロジェクト task を開く
  2. 左メニュー Firestore Database ＞ 「ルール」 タブをクリック
  3. 以下のコードを貼り付けて右上 「公開」 ボタンを押してください
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}

GitHub Pages 公開ガイド

Firebase 設定 (task)

このアプリは Firebase プロジェクト task に接続しています。

ステップ1: GitHub Pages への公開手順

  1. GitHub で新しいリポジトリを作成します（例: my-task-app）。
  2. このコードを index.html という名前でリポジトリの直下に保存してコミット・プッシュします。
  3. GitHub の Settings > Pages に移動し、Branch を main / root に設定して Save します。

ステップ2: Firebase 承認済みドメインの登録 (重要!)

Google ログインを許可するため、ご自身のドメインを承認登録してください。

  1. Firebase Console にアクセスし、プロジェクト task を開きます。
  2. 左メニュー Authentication > 設定 > 承認済みドメイン タブを開きます。
  3. 「ドメインの追加」 をクリックし、GitHub Pages のドメイン（例: username.github.io）を入力して保存します。
